Onde consigo a chave?
  1. No GitHub, abra Settings, Developer settings, Personal access tokens, Fine-grained tokens.
  2. Crie um token só para o repositório do sistema, com a permissão Contents em Read and write.
  3. Copie o token e cole aqui. Ele fica guardado só neste navegador.

Recebeu convite para o sistema? Aceite o convite do GitHub e crie a sua chave em Tokens (classic), marcando só “repo”. Cada pessoa usa a própria chave: tudo o que você gravar sai com o seu nome.
